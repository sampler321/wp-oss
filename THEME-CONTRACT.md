# Theme contract

Every theme in `themes/<slug>/` follows this. `tools/test-theme.mjs` enforces it, and a theme is not done until the test passes.

## 1. Native only
- A **block theme** in the style of Automattic's themes: `theme.json`, `templates/*.html`, `parts/*.html`, `patterns/*.php`, `styles/*.json`.
- **Only core blocks** (`core/*`) in templates, parts and patterns. No custom blocks, no shortcodes, no page builders.
- WooCommerce blocks (`woocommerce/*`) are allowed **only** in WooCommerce templates (`archive-product.html`, `single-product.html`, `taxonomy-product_cat.html`, `product-search-results.html`, `page-cart.html`, `page-checkout.html`, `order-confirmation.html`), and only in shop themes. They load only when WooCommerce is active.
- No functionality in the theme: no custom post types, no custom blocks. Portfolio items, projects, episodes, releases and so on are **posts in categories**, shown with Query Loop. `functions.php` is optional and limited to registering block style variations and pattern categories. It must not enqueue CSS files.
- Requires WordPress 6.7+, PHP 7.4+.

## 2. Everything tokenised in theme.json (editable in Site Editor > Styles)
- `settings.color.palette`: all colours, with semantic slugs: `base`, `contrast`, `accent`, `accent-2` (optional), `surface`, `line`, plus any theme-specific colours. Set `defaultPalette`, `defaultGradients` and `defaultDuotone` to false. Custom colour pickers stay available.
- `settings.typography.fontFamilies`: every font is **self-hosted** in `assets/fonts/*.woff2` via `fontFace` (no Google Fonts calls). Slugs are `display` and `body` (an optional third `accent` face is allowed). **No monospace fonts** anywhere: not as captions, labels, prices, dates or "technical" details. Small monospace labels are a recognised AI-design tell. Use the body face at a small size, tabular figures (`font-variant-numeric`) for prices and times.
- `settings.typography.fontSizes`: presets `x-small, small, medium, large, x-large, xx-large, display` (fluid where useful). `defaultFontSizes: false`. **No custom font sizes in block markup.** Use the `fontSize` attribute with a preset slug.
- `settings.spacing.spacingSizes`: slugs `10…80`, with `defaultSpacingSizes: false`. Block spacing in markup must be `var:preset|spacing|NN` or `0`.
- `settings.shadow.presets` (or `defaultPresets: false` if the theme has no shadows).
- Radii, borders, button styles and link styles live in `styles.elements` and `styles.blocks`, never in markup.
- **No hex colours in templates, parts or patterns.** Use `backgroundColor`/`textColor`/`borderColor` preset slugs.
- Section looks (inverted, accent, outlined, etc.) are **block style variations** in `styles/sections/*.json` with `blockTypes` (the WP 6.6+ section styles). Apply them with `className: is-style-<slug>`.
- If CSS is unavoidable (e.g. `text-wrap`, a hover detail), put it in `theme.json` `styles.css` or a block's `css` key, where it shows as editable "Additional CSS". Keep it short. No `style.css` rules beyond the header.
- 3 style variations in `styles/*.json` (palette + typography swaps), named in the research entry.

## 3. Required files
```
themes/<slug>/
  style.css            header only (see below)
  theme.json           version 3
  readme.txt           WordPress.org format; credits for fonts and images with licences
  screenshot.png       1200×900, generated by the test harness
  templates/           index, home, front-page, page, single, archive, search, 404 (+ theme-specific page-*.html, single-*.html)
  parts/               header.html, footer.html (+ variants)
  patterns/            *.php with the standard header (Title, Slug `<slug>/<name>`, Categories, Block Types where relevant, Inserter)
  styles/              3 variations + sections/*.json
  assets/fonts/        woff2 + OFL licence files
  assets/images/       demo images (CC0/public domain, credited in readme.txt), max 1600px, JPEG q80 or WebP
  functions.php        optional (see §1)
```

`style.css` header fields: Theme Name, Theme URI (https://github.com/sampler321/wp-oss), Author (WP-OSS), Description (one plain sentence, who it is for), Version 1.0.0, Requires at least 6.7, Tested up to 6.9, Requires PHP 7.4, License GPL-2.0-or-later, License URI, Text Domain `<slug>`, Tags.

## 4. Patterns and demo content
- **At least 40 patterns** per theme (round 2, see REVISION-BRIEF.md), mostly from the research entry's Patterns list, including the Signature pattern and at least 3 Nice-to-haves built as patterns (e.g. a scheduled notice bar, a printable price list, find us, credentials row).
- Page-layout patterns (`Block Types: core/post-content`) for each demo page, so "Add page" offers them.
- Copy is written in the owner's voice following `research/ANTI-AI-WRITING.md`: named people, real-feeling places and numbers, one opinion, one limit. **Zero em dashes.** Sentence case headings and buttons. `copylint` must pass with no S5 findings.
- Images: pattern images use `<?php echo esc_url( get_theme_file_uri( 'assets/images/x.jpg' ) ); ?>` with literal, specific alt text.
- Strings in patterns are translatable (`esc_html_e( '…', '<slug>' )`) where practical.

## 5. Design
- **Banned AI-template details:** monospace fonts; the middle dot `·` as a separator (use a comma, slash, line break or real list); zero-padded index labels such as `01`, `02 /`, `03 ·` above headings or on cards; tracked-out all-caps eyebrow labels; "Est. 2014" badges. Lists and steps use a real ordered list or plain numbers in text.
- Follow the idea's **Style** block in `research/THEME-IDEAS.md`, as amended by the owner's brief in `BUILD-STATUS.md`. The owner's brief wins.
- The display font must match `research/FONT-REGISTRY.md` unless the owner's brief changes the direction. If it changes, claim a new unused family in the registry.
- Run the sniff test in `research/ANTI-VIBE.md` §3. No purple gradients, no shadcn-style cards, no pill badge above the H1, no icon-in-circle feature grids, no stat rows, no fade-in on scroll, no warm off-white + serif default look.
- Mobile first: every template must work at 390px.
- Accessibility: 4.5:1 text contrast on every palette pair used for text, visible focus styles, `prefers-reduced-motion` respected.

## 6. Demo
`demos/<slug>/content.json` describes the demo site (see `demos/_example/content.json`): site title and tagline, pages (each built from a pattern), posts (title, category, featured image, pattern or content), navigation links, front page, and optional WooCommerce products. `tools/lib/demo-builder.php` turns it into a site inside Playground.

## 7. Done means
`node tools/test-theme.mjs <slug>` exits 0. That covers static checks, theme.json schema, PHP lint, core-blocks-only, tokenisation, copylint, Playground boot, every demo page returns 200 with no PHP notices, zero invalid blocks in the editor, and screenshots.
