# WP-OSS

Open-source native WordPress block themes for small, independent businesses and creatives. Every theme uses only core blocks, and every colour, font, size and spacing value lives in `theme.json`, so the whole look is editable in Appearance > Editor > Styles.

- `themes/`: the themes, one folder each, ready to zip and install.
- `demos/`: demo content, Playground blueprints and test reports for each theme.
- `tools/`: build, test, export and deploy tooling (WordPress Playground, Playwright).
- `research/`: the research behind the themes (310 ideas, anti-vibe and anti-AI-writing guides, font registry).

See `THEME-CONTRACT.md` for the rules every theme follows and `BUILD-STATUS.md` for the list and live demos.
