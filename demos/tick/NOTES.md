# Tick: notes

- Direction: the watchmaker's bench ledger. Drafting-film grey page, graphite type, brass rules, hairline column guides behind the front-page opening, and every price list set as ruled lines with dotted leaders, the way a workshop price card is written out.
- Persona: Wróblewski, zegarmistrz, a three-generation workshop on Piotrkowska in Łódź since 1961. Copy in English, prices in złoty, Polish place names.
- Fonts: Poltawski Nowy (display, a revival of Adam Półtawski's Polish book type of 1928) and Public Sans (body). The registry face Azeret Mono is a monospace, which the new rule bans, so Poltawski Nowy is newly claimed (see fonts-claim.txt). Both families include the Latin Extended subset, added as extra fontFace entries with unicode ranges, because the font tool only keeps basic Latin and Polish needs ł, ś, ż.
- Palette: drafting film #F2F3EF, graphite #1B2430, brass #A57A2C (rules and buttons with ink text), plate grey, hairline, case oxblood only for sold flags.
- Signature: Send it in page with one details block of packing steps per kind of timepiece and a printable send-in slip (header and footer hidden in print). Also: free-estimate statement, house calls with the "after 20 to 25 years a visit is not enough" note, intake notice, warranty line, glossary, dial status markers on pieces for sale.
- Core-block limits: the research's Interactivity API item picker and Jetpack form became details blocks and a print-and-fill slip. "Today's hours" is a static table, since blocks can't read the clock.
