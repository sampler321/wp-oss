Drum is for risograph studios and print co-ops. Everything that holds content sits in a box with a thick black border and a hard offset shadow; the shadows are theme.json presets (Hard, Hard small, Hard large, Pink offset, Blue offset), so you can change them in Styles.

The ink chart uses the palette: each swatch is a colour preset, so a style variation re-inks the chart. The "Overprint proof" pattern stacks two images tinted with the blue and pink ink duotones and blends them, which gives a rough preview of how two riso layers overprint. Replace the images with your own layers.

It needs WooCommerce for the shop (swatch cards, paper packs, stationery, print club). Print jobs are posts in the Jobs category. Print with us, Inks, Paper and Workshops are built from page patterns.
