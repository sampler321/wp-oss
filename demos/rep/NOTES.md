# Rep: notes

- Direction: "index catalogue" for a London illustration agency (Holloway Pask). A white page ruled in 1px black, a dense grid of small 4:5 tiles captioned with work, artist and client plus year, and a roster set as a two-column list of large names. Vermilion (#E24E1B) only for hover on names and the enquiry band.
- Fonts: Clash Grotesk only (Fontshare, variable 200 to 700). The planned IBM Plex Mono captions were dropped under the no-monospace rule; captions are Clash Grotesk at small size with tabular figures.
- Content model: works are posts; each artist is a category (so the Categories block is the roster and each artist page is a category archive with the bio from the term description, their work at native ratio and the agents' contacts); styles, subjects and disciplines are tags, so every style page pulls credited work from the whole roster (the signature).
- Also: discipline filter row (Illustration, Animation, Photography as tags), browse-by-style image index, a separate animation roster page, "what we need to quote" checklist, agents with direct email and phone, recent commissions, news, a studio-visit interview and a short About in German, French, Portuguese and Polish.
- Variations: Salon, Black book, Primary (blue accent).
- Core-block limits: the demo builder can't create child categories, so disciplines are tags rather than parent categories. The cursor-following preview image on roster names needs JS and was left out; names change colour on hover instead.
