# Good Dog: notes

- Direction: a rainbow sweet shop for dogs. The owner asked for more rainbows and more fun, so the research's saddlery look was dropped. The joke that runs through it: dogs see mostly blue and yellow, so the six colours are for the humans.
- Fonts: Cherry Bomb One (display, claimed in fonts-claim.txt, not in the registry) and Mulish (body, tabular figures in tables). No monospace.
- Palette: white and navy ink, six bright sticker colours (coral, orange, yellow, grass, sky, bubblegum) that all carry navy text at 5:1 or better. Tomato for links, lead blue for focus rings.
- Signature: the size guide (nose to tail, times 1.25) with a worked example and a highlighted row, plus the collar guide, sighthound collars and crate mats cut to named crates.
- Other distinctive bits: the six-stripe rainbow ribbon under the header and above the footer (a separator block style), shop split into colour-swatch tiles, sticker style with hard offset shadows, slightly tilted photos, dog wall as the posts page.
- Nice-to-haves built as patterns: sighthound collars, washing guide, dog wall with photos, crate bedding by crate model, engraved name tag with character limits, lead-time bar, closed-for-Christmas notice.
- Core-block limits: the recommended size row is a static highlight (mark) for the worked example, since core blocks can't compute a size from input. The rainbow ribbon uses a hard-stop linear-gradient in a custom theme.json property.
- Screenshot note: portrait featured images sometimes render blank in the full-page test screenshots because they are lazy-loaded below the fold. They load normally in a browser.
