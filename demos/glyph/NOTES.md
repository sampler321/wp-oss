# glyph: notes

- Direction: "specimen sheet". White paper, black type, proof-mark red only for margin notes (sizes, features, prices). Most of every page is type set very large.
- Fonts: Ronzino by Collletttivo (registry face, OFL, downloaded from github.com/collletttivo/ronzino because fetch-fonts only covers Google and Fontshare) for UI, headings and the grotesk specimens; Petrona (Google, variable 100 to 900) as the foundry's serif. The demo presents them as the fictional foundry's Margo Grotesk and Harbour Serif, with a footer and readme note that they are stand-ins. Slugs: display and body are Ronzino, accent is Petrona (two families).
- Palette: paper #FFFFFF, type black #0D0D0D, proof red #CC2A17, galley #F1F0EC, rule #D5D3CC.
- Specimen built from core blocks only: specimen-hero (family name at the "specimen" size preset), specimen-sizes (one voice at 96/48/24/16 pt, a static stand-in for a tester), styles-list (each style set in itself with its price right-aligned), glyph-grid (single characters in square cells via a grid Group and a section style), weight-waterfall (Petrona 100 to 900) and a grotesk weights block, opentype-features, language-support, details, in-use, pairing, licence-table, company-size pricing, trials with a "last updated" line, free-font donation block, custom type.
- WooCommerce: six licences as simple products (family desktop, single style, web, variable web, logo). Company-size and licence-type variations would need variable products, which the demo builder does not create, so sizes are explained in a table.
- Core-block limits: no live type tester or axis sliders (needs JS); the OpenType ss01 demo uses the real single-storey a character instead of font-feature-settings.
