Seed is for artists who work with code and pen plotters. Each work is a post whose page is split into Gallery (a ruled grid of numbered outputs, like a contact sheet) and Info (statement, edition size, release date, platform link). Use the "Work page: gallery and info" pattern when you write a new work, then replace the outputs with your own and caption each one with its number.

Works are sorted into the categories Digital, Physical and Spatial, which the tabs link to; the Index page lists every work as one line. Live sketches are never embedded to run on their own: the "Live sketch" pattern shows a still and a button that opens the running sketch.

The demo outputs were generated for this theme by build/seed_outputs.py and are CC0.
