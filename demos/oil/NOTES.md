# oil: notes

- Direction: catalogue raisonne on a cool gallery-white wall (#F4F5F5). No hero: the front page is the index itself, a sticky 3/12 column (big "Work" title, mediums, years, tags) beside a 4-column grid of uncropped paintings.
- Fonts: Gloock (display, from the registry, one weight used big) and Libre Franklin (body and captions, tabular figures).
- Palette: wall white, lamp black #1C1B19, oxide #8C2F23 used only for links and the gallery red dot. Variations: Salon (dark), Linen, Ultramarine.
- Signature: every sold work keeps its red dot (a CSS dot on the "Sold" tag link) and last price, so the archive doubles as a price record; work pages give size once in cm and once in inches, an availability line, an "Enquire about this work" mailto and a "Describe this work" toggle.
- Year filter uses core Archives (yearly) so /2025/ date archives act as year pages with the year set huge as the title.
- Could not do with core blocks: price-range filter, per-work pre-filled enquiry form (a mailto with the title in the subject is used instead), the wall-scale silhouette from Tom Hammick's site, automatic cm to inch conversion (done at build time for the demo).
- Journal is a page of dated notes rather than posts, so the works query stays pure.
