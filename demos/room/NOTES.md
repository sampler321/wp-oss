# room: notes

- Direction: "decorator's scrapbook". Project stories are told room by room; each room opens with the paint chip for its walls, then a short story with the pieces linked inline and the price after them, so the portfolio doubles as the shop.
- Fonts: Radio Canada Big (registry face) for headings, Karla for text.
- Palette: plaster #F4EFE9, umber ink #2B2522, claret #6E2F3A, putty #E7DED3, plus four paint-chip colours (Lichen, Mustard seed, Setting plaster, Slate sky) that exist as palette entries so the chips stay editable. Square corners everywhere except the arched hero photograph.
- Signature: `room/project-rooms` (room-by-room story) and `room/room-chapter`; `pieces-in-project` is added to every project page by the single template.
- Nice-to-haves built: the edit (one project as a collection), enquiry instructions (floor plan, photos, budget), credits line, fabric by composition, free sample cuttings, trade account page.
- WooCommerce: nine simple products (lamps, antiques, fabric per metre, wallpaper per roll). No Woo block templates; the defaults inherit theme.json, with a little CSS for buttons and badges.
- Core-block limits: products and projects cannot be related by taxonomy without a plugin, so the "pieces in this project" row is a pattern edited per project. The hover thumbnail on product links from the research was left out (needs JS).
