## Part 4: The 100 theme ideas

**How to read each entry**
- **Templates**: block templates in `templates/` (Woo templates are included when commerce is on).
- **Patterns**: the pre-made block library for that theme. About 40% of patterns are shared across the whole library (see Part 5), and the rest are specific to the theme.
- **Content model**: CPTs/taxonomies/meta supplied by the `wp-oss-companion` plugin and shown through Block Bindings.
- **Signature**: the one feature that makes the theme worth choosing over a generic one.
- **Flare**: the art-school/brutalist angle.
- **Refs**: live sites that already do this well, used for research and benchmarking. Don't copy them.

### I. Visual art

#### 01 · Illustrator: Portfolio + Shop (`ink`)
**For:** freelance illustrators who sell prints and take commissions.
**Templates:** front-page · archive-work · single-work · taxonomy-medium · page-about · page-commissions · page-shop-landing · Woo: archive-product / single-product / cart / checkout / order-confirmation · search · 404
**Patterns (~55):** hero carousel of works, client-logo marquee, about split (portrait + bio), process in 4 steps, commission pricing tiers, FAQ accordion, testimonial wall, CTA strip, newsletter signup, "available as print" product rail, press mentions, sticker-style availability badges, contact block, social links row.
**Content model:** `work` CPT (year, medium, client, dimensions, `print_product_id`). Taxonomies `medium` and `client`.
**Plugins:** WooCommerce, Jetpack Forms, Query Filter.
**Signature:** `/works` is a masonry Query Loop (theme block style `is-style-masonry` using CSS columns). Every image opens in the core lightbox. Filter chips come from the medium taxonomy. A bound "Buy print →" button appears only when the work has a linked Woo product.
**Flare:** a toggleable 12-column grid overlay, oversized handwritten numerals for work IDs, price tags styled like stickers.
**Style variations:** Riso Pink · Newsprint · Night Shift.
**Refs:** {{REFS-01}}

#### 02 · Painter: Studio & Available Works (`oil`)
**For:** painters who sell originals directly and through galleries.
**Templates:** front-page · archive-work (with available/sold/on-loan states) · single-work · archive-exhibition · single-exhibition · page-cv · page-studio · page-enquire
**Patterns (~45):** full-bleed painting hero with caption plate, "wall view" (the painting scaled against a silhouette for size), CV blocks (solo/group/collections/awards/education), exhibition card, studio-visit CTA, gallery representation list, essay/quote block with footnotes, price-on-request enquiry.
**Content model:** `work` (status, price, dimensions in cm/in, medium, year, `location_gallery`). `exhibition` (dates, venue, type solo/group).
**Plugins:** Jetpack Forms, Advanced Query Loop (current/upcoming/past exhibitions).
**Signature:** a per-work "Enquire" form that pre-fills the work title and ID. The "Wall view" pattern shows the real scale of a painting from its dimension meta.
**Flare:** museum-label captions set in mono, an ultra-quiet white cube layout that breaks into a loud red "SOLD" dot.
**Style variations:** White Cube · Salon Hang (dense grid) · Linen.
**Refs:** {{REFS-02}}

#### 03 · Fine-Art Photographer: Series & Editions (`silver`)
**For:** photographers who work in projects/series and sell editioned prints.
**Templates:** front-page · archive-series · single-series (sequenced, one image per viewport) · single-print (Woo) · page-books · page-bio · page-press
**Patterns (~40):** full-viewport image sequence, contact-sheet grid, horizontal scroll strip, series statement, edition info table (size / paper / edition / price), book object card, exhibition list, press quote, colophon.
**Content model:** `series` CPT whose gallery lives in post content. Woo variable products (size × paper). Edition counter meta (`edition_total`, `edition_sold`).
**Plugins:** WooCommerce.
**Signature:** a "Contact sheet ↔ Sequence" view toggle (Interactivity API) on each series. An edition counter block shows "7 / 25 left", bound to stock.
**Flare:** film-rebate borders, frame numbers in the corners, black backgrounds and mono captions.
**Style variations:** Darkroom · Baryta White · Cyanotype.
**Refs:** {{REFS-03}}

#### 04 · Wedding & Portrait Photographer (`vow`)
**For:** solo event and portrait photographers.
**Templates:** front-page · archive-story · single-story (full wedding story) · page-packages · page-about · page-proofing (password-protected) · page-enquire
**Patterns (~50):** hero slideshow, packages/pricing cards, "what's included" checklist, testimonial carousel, featured-in logos, process timeline (enquiry → shoot → delivery), FAQ, availability CTA, venue list, Instagram-style grid.
**Content model:** `story` CPT (couple, venue, date, season). Taxonomies `venue` and `style`.
**Plugins:** Jetpack Forms (date + venue + budget fields), optional Cal.com embed.
**Signature:** client proofing galleries built on core post passwords plus a "favourites" heart that emails a selection list (companion block).
**Flare:** keeps the romance but swaps the script fonts for condensed grotesks and pairs raw flash snapshots with soft film shots.
**Style variations:** Film Grain · Editorial · Flash.
**Refs:** {{REFS-04}}

#### 05 · Sculptor / Installation Artist (`plinth`)
**For:** artists whose work is spatial, time-based, or site-specific.
**Templates:** front-page (project index) · single-project (video + install shots + process) · archive-project · page-cv · page-texts
**Patterns (~40):** looping video cover, install-shot grid, process diary strip, technical spec table (materials / dimensions / duration / edition), floor plan + caption, essay with footnotes, exhibition credit block, commissioned-by line.
**Content model:** `project` (year, materials, dimensions, location, commissioner, `video_url`).
**Plugins:** none required. Optional Advanced Query Loop.
**Signature:** the front page is a text-only chronological index table. Hovering a row shows a cursor-following preview image (Interactivity API).
**Flare:** the "architectural drawing" look: hairline rules, dimension arrows, plan-view thumbnails.
**Style variations:** Concrete · Plaster · Rust.
**Refs:** {{REFS-05}}

#### 06 · Ceramicist: Drop Shop (`kiln`)
**For:** potters who release small batches that sell out in minutes.
**Templates:** front-page (next-drop countdown) · Woo shop · single-product · page-workshops · page-stockists · page-care
**Patterns (~45):** countdown hero, "sold out" grid state, email-me-for-next-drop, workshop cards, stockists map, glaze swatch grid, care instructions, process photo essay, wholesale enquiry.
**Content model:** Woo products with a `drop` taxonomy. `workshop` handled as Woo products with a fixed number of spots.
**Plugins:** WooCommerce, MailPoet/Jetpack Newsletter, OpenStreetMap block.
**Signature:** a drop countdown block (Interactivity API) that switches the shop from "preview" to "live" at a set timestamp, plus a "sold out, get notified" pattern.
**Flare:** thumb-print textures, earthy palettes against hard black type, glaze swatches presented like paint chips.
**Style variations:** Stoneware · Celadon · Raku.
**Refs:** {{REFS-06}}

#### 07 · Tattoo Studio (`flash`)
**For:** independent tattoo artists and small studios.
**Templates:** front-page · archive-artist · single-artist (portfolio + books-open status) · archive-flash · page-booking · page-aftercare · page-faq
**Patterns (~45):** artist roster cards with "books open/closed" badge, flash sheet grid, claimed/unclaimed flash, booking-request form (placement, size, reference upload, budget), deposit policy, aftercare steps, studio hours, guest artist spots.

**Flare:** photocopier zine style: halftone, stamps, red and black on off-white.
**Style variations:** Traditional · Blackwork · Neon Sign.
**Refs:** {{REFS-07}}

#### 08 · Webcomic / Comic Artist (`panel`)
**For:** webcomic creators and indie comic authors.
**Templates:** front-page (latest page) · single-comic-page · archive-chapter · archive-comic (grid of all pages) · page-cast · page-shop · page-about

#### 09 · Muralist / Street Artist (`wall`)
**For:** muralists, sign painters, and public artists.
**Templates:** front-page · archive-mural · single-mural · page-map · page-commissions · page-process
**Patterns (~40):** full-bleed wall shot, before/after slider, mural map, commission process (brief → sketch → wall), client/city logos, time-lapse video, quote request.

#### 10 · Riso & Printmaking Studio (`drum`)
**For:** risograph studios, screenprinters, and printmakers who sell editions and offer print services.

#### 11 · Generative / Creative-Code Artist (`seed`)
**For:** artists working with code, p5.js, shaders, plotters.

#### 14 · Degree Show / Graduate Showcase (`class-of`)
**For:** art school graduating classes, student-run shows, course units. A core art-school theme.
**Templates:** front-page · archive-student (filter by discipline) · single-student · archive-discipline · page-events · page-visit · page-catalogue
**Patterns (~40):** student card grid, discipline filter, student page (statement / works / links / contact), events programme, floor map, catalogue download, sponsors, tutor list.

**Style variations:** Crit Wall · Riso Catalogue · Open Studio.

### II. Architecture & spatial

#### 16 · Architecture Studio (`plan`)
**For:** small and medium architecture offices (2–30 people).
**Templates:** front-page · archive-project (index table + grid toggle) · single-project · taxonomy-typology · archive-person · page-office · page-careers · page-press · archive-news
**Patterns (~60):** project index table (no. / name / typology / location / status / year), image-led project hero, project facts sheet, drawings gallery (plans / sections), large-quote, team grid, awards list, publications list, press kit download, job listing, office map, "under construction" status badge.
**Content model:** `project` (number, typology, status: competition/in-progress/completed, location, year, client, area m², collaborators). `person`.
**Plugins:** Query Filter, Advanced Query Loop.
**Signature:** an index view that sorts by any column (Interactivity API) and switches between table, grid, and map views.
**Flare:** blueprint and hairline aesthetic, project numbers as the main navigation, a grey 1:100 scale bar as a decorative element.
**Style variations:** Blueprint · Concrete · Tracing Paper · Swiss.
**Refs:** {{REFS-16}}

### III. Design & digital

#### 22 · UX / Product Designer Case Studies (`case`)
**For:** UX/UI/product designers job-hunting or freelancing.
**Templates:** front-page · archive-case-study · single-case-study · page-about · page-resume · page-now · archive-note
**Patterns (~60, mostly case-study blocks):** case study hero (role / timeline / team / tools), problem statement, TL;DR summary card, research insights cards, persona card, journey map, before/after UI comparison, annotated screenshot, design system tokens grid, metric/results strip ("+32% activation"), quote from stakeholder, "what I'd do differently", process timeline, prototype embed (Figma), next case study CTA, password-protected NDA case.
**Content model:** `case_study` (role, company, year, duration, team, platform, outcome metric).
**Plugins:** none required (Figma embed is core).
**Signature:** synced case-study patterns with pattern overrides, so a user can add a "Research insight" and keep consistent styling. Sticky chapter progress bar. NDA case studies behind passwords.
**Flare:** exposed UI annotations (redlines, spacing specs) used as decoration.
**Style variations:** Redline · Figma Canvas · Paper Prototype.
**Refs:** {{REFS-22}}

#### 23 · Graphic Designer / Typographer Index (`grid`)
**For:** graphic designers, editorial designers, typographers.
**Templates:** front-page (pure index list) · single-project · archive-project · page-info · page-colophon
