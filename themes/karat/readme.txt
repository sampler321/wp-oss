== Description ==

A shop and commission site for independent jewellers and goldsmiths who sell a small collection and make bespoke rings.

Every colour, font, size and spacing value lives in theme.json, so the whole look can be changed in Appearance > Editor > Styles. The theme uses only core WordPress blocks.

Demo content: https://github.com/sampler321/wp-oss/tree/main/demos/karat
