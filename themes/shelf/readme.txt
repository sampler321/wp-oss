== Description ==

A loud, illustrated site for independent bookshops that sell online, run events and send a hand-picked book a month.

Every colour, font, size and spacing value lives in theme.json, so the whole look can be changed in Appearance > Editor > Styles. The theme uses only core WordPress blocks.

Demo content: https://github.com/sampler321/wp-oss/tree/main/demos/shelf
