== Description ==

A roster and portfolio site for small agencies that represent illustrators, animators and photographers and pitch them to publishers and brands.

Every colour, font, size and spacing value lives in theme.json, so the whole look can be changed in Appearance > Editor > Styles. The theme uses only core WordPress blocks.

Demo content: https://github.com/sampler321/wp-oss/tree/main/demos/rep
