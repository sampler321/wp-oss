== Description ==

A podcast theme for investigative and true-crime series, with case archives, episode file cards, sources, a dated corrections log and content warnings.

Evidence is built for investigative and true-crime podcasts that run one case per season. Episodes are posts; each case is a category with its own archive page, and a third category holds updates and corrections. Every episode opens with a manila file card (case, part, date, length), then the player, a content warning, chapters whose timestamps open the audio at that point, numbered sources and a transcript in a fold.

The theme includes a sources and corrections page with a dated log, a "how we report" page, a tips page with safe contact details and help lines, an "in memory" pattern for the person harmed, a document quote with redaction bars, an evidence board of tagged exhibits and a season-break notice. All photos are shown in greyscale by default; remove the filter in Appearance > Editor > Styles > Blocks > Image > Additional CSS.

The demo cases and people are invented. Stand-in audio is a CC0 LibriVox reading on Wikimedia Commons. Replace it with your own files.

Every colour, font, size and spacing value lives in theme.json, so the whole look can be changed in Appearance > Editor > Styles. The theme uses only core WordPress blocks.

Demo content: https://github.com/sampler321/wp-oss/tree/main/demos/evidence
