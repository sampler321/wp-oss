== Description ==

A catalogue shop theme for independent stationery shops and notebook makers who sell by ruling, paper weight and size.

Every colour, font, size and spacing value lives in theme.json, so the whole look can be changed in Appearance > Editor > Styles. The theme uses only core WordPress blocks.

Demo content: https://github.com/sampler321/wp-oss/tree/main/demos/paper
