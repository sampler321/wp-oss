== Description ==

A clean, grid-based theme for Gas Safe registered plumbers and heating engineers, with a price index, area pages and a quote section that sorts emergencies from routine jobs.

Every colour, font, size and spacing value lives in theme.json, so the whole look can be changed in Appearance > Editor > Styles. The theme uses only core WordPress blocks.

Demo content: https://github.com/sampler321/wp-oss/tree/main/demos/pipe
