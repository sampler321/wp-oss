== Description ==

A portfolio for independent UX and product designers who write long case studies with research, before and after screens, and results.

Every colour, font, size and spacing value lives in theme.json, so the whole look can be changed in Appearance > Editor > Styles. The theme uses only core WordPress blocks.

Demo content: https://github.com/sampler321/wp-oss/tree/main/demos/case
