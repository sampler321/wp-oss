== Description ==

A picture-led site for artist-run spaces and collectives, with a numbered programme archive, membership, opportunities and a committee page.

Every colour, font, size and spacing value lives in theme.json, so the whole look can be changed in Appearance > Editor > Styles. The theme uses only core WordPress blocks.

Demo content: https://github.com/sampler321/wp-oss/tree/main/demos/commons
