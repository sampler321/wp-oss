== Description ==

A specimen site and licence shop for small independent type foundries, built from large type, glyph grids, weight waterfalls and a plain licence table.

Every colour, font, size and spacing value lives in theme.json, so the whole look can be changed in Appearance > Editor > Styles. The theme uses only core WordPress blocks.

Demo content: https://github.com/sampler321/wp-oss/tree/main/demos/glyph
