== Description ==

A loud, plain portfolio for muralists and sign painters, with every wall listed, lost walls kept in their own archive, and quotes for homes, businesses and schools.

Wall is for muralists, sign painters and street artists. The front page sets the artist's name across the full width like a wall piece, then shows every mural in a freeform grid where each photo has its own size and drop.

Each mural is a post with a featured image, a type category (Homes, Businesses, Schools, Public walls) and tags for the city. When a wall is painted over or knocked down, add the tag "Gone": its photo turns grey with a "Painted over" label, and it moves to the Gone archive at /tag/gone/ instead of disappearing. Put the "Mural facts" pattern in every mural post and change its status line.

The Map page lists every public wall with a link to OpenStreetMap. Commissions, Prints and About are built from page patterns.

Every colour, font, size and spacing value lives in theme.json, so the whole look can be changed in Appearance > Editor > Styles. The theme uses only core WordPress blocks.

Demo content: https://github.com/sampler321/wp-oss/tree/main/demos/wall
