== Description ==

A two-colour duotone site for independent bands and solo musicians, built around a live dates page, releases and a small merch shop.

Every colour, font, size and spacing value lives in theme.json, so the whole look can be changed in Appearance > Editor > Styles. The theme uses only core WordPress blocks.

Demo content: https://github.com/sampler321/wp-oss/tree/main/demos/amp
